🌸 VogueNest
VogueNest is an editorial-grade, full-stack e-commerce web application built for premium wardrobe curation and luxury lifestyle retail. Designed with a cozy, minimalist pastel-sage aesthetic, it pairs a high-fashion visual experience with a robust, enterprise-standard backend architecture.

✨ Key Features
Curated Editorial Aesthetics: Crafted with a custom pastel-cream background, forest sage accents, terracotta highlights, and clean typography (Playfair Display & Plus Jakarta Sans).

Dual-Role Session Management: Unified authentication routing that automatically directs regular shoppers to their active cart and verified administrators straight to the secure product inventory portal.

Hybrid Asynchronous Cart Engine: Seamlessly handles guest state via local storage and safely syncs and persists user shopping bags to the database upon login.

Dynamic Admin Inventory Control: A protected dashboard portal enabling authorized admins to add, manage, and catalog products in real-time.

Secure Checkout Pipeline: Features a complimentary luxury shipping calculation engine and automated transactional database flushing upon order completion.
